## Features

- 📝 **Full Blog CRUD** — Create, edit, publish, and delete blog posts using rich text layouts.
- 💬 **Comment Threading** — Leave feedback on posts and vote on comment ratings.
- 🔐 **Firebase Auth** — Secure third-party Google and email credentials sign-in/registration.
- 📊 **Admin Oversight Panel** — Administrative interface to audit posts, comments, and user accounts.

## Tech Stack

### Frontend

- **Framework**: React.js, React Router
- **State**: Redux Toolkit
- **Styling**: Tailwind CSS & Flowbite React
- **Auth Service**: Firebase Client SDK

### Backend & DB

- **Runtime**: Node.js & Express.js
- **Database**: MongoDB with Mongoose
- **Tokens**: JWT for session auth

## Architecture Highlights

Insight combines Firebase Authentication for client sessions with JWT tokens for API route authorization. The backend validates requests via middleware, verifying both user IDs and admin roles before authorizing modifications on MongoDB documents.
