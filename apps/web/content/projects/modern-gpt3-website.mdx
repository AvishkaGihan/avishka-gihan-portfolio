A modern frontend landing page showcasing OpenAI's GPT-3 capabilities. Built with React and Vite, the platform demonstrates high-fidelity UI/UX layouts, clean BEM-styled stylesheets, and responsive content grids.

## Preview

![GPT-3 Web Interface](/images/projects/modern-gpt3-website/screenshot.png)

## Features

- 🎨 **Futuristic Design** — Glowing neon gradients and abstract geometric backdrops.
- 📱 **Fluid Responsiveness** — Pixel-perfect alignment scaling down to mobile viewports.
- ⚛️ **Modular React Cards** — Divided sections representing blog posts, feature lists, and CTAs.
- ⚡ **Vite Bundler** — Optimized asset loading and instant hot reloading.

## Tech Stack

- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Vanilla CSS3 using BEM (Block-Element-Modifier) naming conventions

## Architecture Highlights

This project utilizes BEM CSS architecture to maintain isolated component styling, eliminating global class naming collisions and ensuring rendering performance stays fast.
