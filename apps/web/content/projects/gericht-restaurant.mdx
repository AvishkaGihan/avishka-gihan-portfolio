Gerícht is a modern, responsive website designed specifically for a fine dining restaurant. Built with React and Vite, the platform features a premium dark UI/UX with smooth scroll animations, interactive menus, media integration, and a comprehensive awards display section.

## Preview

![Gerícht Restaurant Website](/images/projects/gericht-restaurant/screenshot.png)

## Features

- 🎨 **Elegant UI/UX Design** — Dark-themed, modern layout tailored for high-end dining aesthetics.
- 📱 **Fully Responsive Layout** — Fluid scaling optimized across mobile, tablet, and desktop viewports.
- 📋 **Interactive Menu Showcase** — Easy-to-read sections highlighting the food and beverage offerings.
- 🏆 **Awards & Recognition** — A dedicated section highlighting culinary milestones and restaurant achievements.
- 🖼️ **Image Scroll Gallery** — Custom horizontal scrolling image gallery showcasing the dining atmosphere.
- 🎥 **Video Integration** — Video showcase elements to capture the fine-dining experience.
- ✉️ **Newsletter Subscription** — Fully styled call-to-action subscription block.

## Tech Stack

- **Framework**: React 18
- **Tooling**: Vite
- **Styling**: Vanilla CSS3 configured with BEM (Block-Element-Modifier) naming conventions
- **Icons**: React Icons

## Architecture Highlights

Gerícht is built using modular React components matching BEM naming patterns for CSS architecture.

**CSS BEM Methodology**  
By adhering to Block-Element-Modifier styling conventions, the project prevents style bleed and ensures the CSS structure is clean and easy to maintain as the site scales, keeping loading times fast and rendering smooth.
