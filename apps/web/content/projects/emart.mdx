## Features

- 🛒 **Full-Featured Shopping Cart** — Seamlessly add, remove, and manage cart product quantities.
- 💬 **Product Reviews & Ratings** — Real-time user feedback logging and star rating systems.
- 🎠 **Trending Product Carousel** — Discover popular products at a glance on the homepage.
- 🔍 **Search & Pagination** — Find items instantly and browse catalog results with ease.
- 📊 **Admin Dashboard** — Complete CRUD operations for products, order processing management, and user permissions.

## Tech Stack

- **Frontend**: React, Redux Toolkit (state management), Bootstrap
- **Backend & Logic**: Node.js, Express
- **Database**: MongoDB with Mongoose ORM
- **Security**: bcrypt (password hashing), JSON Web Tokens (JWT)

## Architecture Highlights

eMart decouples client-side presentation from backend business logic. Using Redux Toolkit, client state is updated transactionally. The backend API handles Clarifai operations securely, manages MongoDB transactions, and enforces authentication gates on sensitive admin routes.
