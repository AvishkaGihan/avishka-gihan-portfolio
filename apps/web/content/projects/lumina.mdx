Lumina is a platform designed for sharing and exploring AI prompts, encouraging creativity and collaboration among creators. It allows users to discover the power of AI-generated content, share their best prompts, and unlock their creative potential in a community-driven space.

## Features

- **Share & Discover Prompts** — Post your most effective AI prompts and search through a rich repository of prompts shared by other creators.
- **Collaborative Community** — Connect and collaborate with other prompt engineers and digital creators.
- **User Profiles** — Manage your created prompts, edit postings, and view user-specific insights.
- **Seamless Authentication** — Secure NextAuth.js integration featuring third-party Google sign-in.
- **Modern Responsive Design** — Styled beautifully with Tailwind CSS for high performance across all mobile and desktop layouts.

## Tech Stack

- **Framework**: Next.js
- **Authentication**: NextAuth.js (with Google provider)
- **Database & Modeling**: MongoDB & Mongoose
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## Architecture Highlights

Lumina utilizes Next.js with App Router for building a performant, SEO-friendly prompt directory.

**Dynamic Feeds**  
Prompts are stored as structured documents in MongoDB. The search flow is designed to fetch, filter, and render prompts instantly based on prompt body content, creators, or categorized hashtag labels.

**Session Management**  
Using NextAuth.js, Lumina provides seamless authentication. User details and credentials are securely serialized, while user profiles directly connect to database relations containing all prompts created by that specific account.
