Brainwave is a modern, responsive landing page designed for an AI-powered chat and collaboration application. Built with React, Vite, and Tailwind CSS, it showcases dynamic frontend design featuring smooth grid animations, custom illustrations, and interactive pricing tier layouts.

## Preview

![Brainwave Preview](/images/projects/brainwave/preview.png)

## Features

- 🎨 **Premium UI/UX Design** — High-end visual system optimized for fluid responsiveness across all screens.
- ⚡ **Vite-Powered Frontend** — Next-generation developer tooling for hot-reloading and lightning-fast asset builds.
- 🤖 **AI Showcase** — Interactive product showcase sections demonstrating advanced chat features and smart response suggestions.
- 🤝 **Collaboration & Productivity** — Custom sections highlighting team workspaces and document sharing capabilities.
- 💎 **Interactive Pricing Tables** — Beautifully structured grids representing tiered subscription structures and enterprise options.

## Tech Stack

- **Framework**: React 18
- **Tooling**: Vite
- **Styling**: Tailwind CSS
- **Assets**: Custom SVG illustrations and SVG grid patterns

## Architecture Highlights

Brainwave utilizes React's component architecture to separate sections (e.g. _Header_, _Hero_, _Benefits_, _Pricing_) into independent files, ensuring codebase clean-coding. It leverages Tailwind CSS utility classes combined with custom configurations to govern typography, spacing, and the dark-mode color scheme.
