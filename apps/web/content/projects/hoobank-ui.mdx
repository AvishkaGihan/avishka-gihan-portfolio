HooBank UI is a cutting-edge front-end landing page designed to provide a sleek, intuitive, and highly modern banking user interface. Leveraging React and Tailwind CSS, it offers a responsive layout and custom layout animations.

## Preview

![HooBank Landing Page](/images/projects/hoobank-ui/screenshot.png)

## Features

- 🎨 **Modern Design Theme** — Custom dark-indigo styling with vibrant background gradient highlights.
- 📱 **Fully Responsive Grid** — Fluid alignment across all viewports from mobile screens to desktop monitors.
- ⚡ **Vite Bundler** — Fast hot module reloading and optimized asset bundlers.
- ⚛️ **Component-Based UI** — Reusable React components organizing the header, CTA, statistics, and billing cards.

## Tech Stack

- **Framework**: React 18
- **Tooling**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Custom SVG icons and assets

## Architecture Highlights

HooBank UI organizes content using atomized React components, allowing quick layout edits and clean stylesheet setups. It demonstrates modern utility-first CSS practices to build abstract gradients and glassmorphism elements.
