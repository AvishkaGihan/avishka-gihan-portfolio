Omnifood is a landing page for an AI-powered healthy meal subscription service. It showcases tailored dietary options, testimonials, meal plans, and interactive call-to-actions.

## Preview

![Omnifood Landing Page](/images/projects/omnifood/screenshot.png)

## Features

- 🍎 **AI Meal Planning** — Custom sections showing sample meal details, ingredients, and nutritional information.
- 📱 **Mobile Responsive Design** — Custom grid layouts adapting dynamically across devices.
- 📊 **Interactive Pricing Tier Grid** — Side-by-side plan comparisons with structured CTAs.
- 💬 **Testimonial Slider** — Integrated client review sections and interactive food grids.

## Tech Stack

- **Frontend**: Semantic HTML5
- **Styling**: Vanilla CSS3 with custom variables and flex/grid systems
- **Logic**: Vanilla JavaScript for responsive mobile navigation toggle

## Architecture Highlights

Omnifood showcases standard, high-performance web optimization using lightweight semantic HTML and pure CSS grids. It holds zero external library dependencies, keeping page load metrics at near-perfect scores.
